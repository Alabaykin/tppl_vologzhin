
## Требования

- Python 3.10+
- `pytest` и `pytest-cov` (для запуска тестов)

---

## Запуск программы

Программа принимает выражение через аргументы командной строки. Выражение можно передавать как в кавычках, так и раздельно пробелами:

```bash
python main.py "3 0 4 ~ 2 ~"
```
или
```bash
python main.py "2 2 + 4 - 4 ~ 2 3 * +"
```

### Формат вывода

Программа выводит состояние стека на каждом шаге.

Пример:
```text
Вычисляем выражение: '3 0 4 ~ 2 ~'
Состояние стека на каждом шаге:
Шаг '3' -> стек: [3]
Шаг '0' -> стек: [3, 0]
Шаг '4' -> стек: [3, 0, 4]
Шаг '~' -> стек: [49]
Шаг '2' -> стек: [49, 2]
Шаг '~' -> стек: [47]

3 0 4 ~ 2 ~ = 47
```
